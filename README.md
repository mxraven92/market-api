# market-api

Legacy backend notes for the NightBazaar marketplace API.

This repository contains old service scaffolding, route sketches, and dashboard integration notes. It is retained for compatibility while the newer internal services are tested.

## Local Run

```bash
npm install
npm run dev
```

## Layout

- `src/server.js` - API bootstrap
- `src/routes/` - route modules
- `src/middleware/` - request middleware
- `config/` - runtime configuration
- `docs/` - operational notes
